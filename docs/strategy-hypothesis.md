# 일봉 추세매매 설계와 검증

2026-10-05 결과: **돌파·청산 7안과 조정 후 회복 1안 모두 미채택**이다. 첫 초안의 3% 손절·5일 보유를 운용 정책으로 확정하지 않는다. 투자금·동시 보유 수·계좌 낙폭 중단선은 미정이다. 이 문서의 연구·전진 관찰은 주문하지 않으며, 별도로 추가한 모의 주문 실험은 [실험실](../README.md#실험실)을 따른다.

## 돌파 진입과 청산

아래는 **신호일별 동일비중 평균 거래수익률**이다. 계좌 누적수익률이 아니다. 수정가격에 대회 비용과 편도 슬리피지 0.1%를 적용했다.

| 5일 만기 비교 | 개발 2025-02-03~12-31 | 검증 2026-01-01~06-30 | 재사용 2026-07-01~10-02 |
| --- | ---: | ---: | ---: |
| 청산 조건 없이 만기 보유 | +0.92% | +2.82% | −5.30% |
| 첫 초안 3% 손절·10일선 이탈 | +0.42% | +1.70% | −4.27% |
| 돌파 기준 아래 종가 청산 | +0.16% | +2.09% | −4.45% |
| 2ATR 종가 추적 청산 | +0.77% | +2.93% | −5.97% |
| 완결 사건 / 신호일 | 420 / 158 | 266 / 85 | 27 / 18 |

- **돌파의 우위:** 5일 만기안의 같은 날짜 유동성 대조군 대비 차이는 −0.31%p / +2.09%p / −2.91%p였다. 상승 지속성은 기간에 따라 달랐다. 1·3·5·10·20일 경로와 10·60일 돌파 민감도도 계산했지만 가장 좋은 사후 보유일·필터로 재선택하지 않았다.
- **정상 변동과 실패:** 개발·검증에서 최종 이익인 5일 거래 중 각각 **21.6%·27.2%**도 보유 중 종가가 진입가보다 3% 이상 낮았다. 3% 하락만으로 실패를 구분할 근거는 부족하다. 이 수치는 사후 진단이며 당시 승패를 알았다는 뜻이 아니다.
- **청산의 대가:** 첫 초안은 개발·검증의 하위 5% 거래손익을 −12.38%→−9.64%, −19.73%→−16.41%로 개선했지만 평균 수익은 줄였다. 조기 청산 거래의 약 25%는 만기까지 보유하면 비용 후 이익이었다. 변동성 청산도 모든 기간에서 개선되지 않았다.
- **비용·불확실성:** 편도 0.2%와 종목별 중복 진입 제거도 검사했다. 7안 모두 개발기간 대조군 차이가 음수였고 검증의 7비교 보정 구간도 통과하지 못했다. 재사용 구간은 신호일이 20일 이하라 신뢰구간을 제시하지 않는다.

[비교 그림](images/daily-trend-2026-10-05.png) · [전체 수치와 검산 메타](../research/daily-trend/results.json). 위 5일 만기안의 최악 거래는 −45.11%이며 저장된 KIS 수정가격 원응답과 일치했다. 당시 원주가·기업행사·실체결을 독립 확인한 값은 아니다.

## 구현한 규칙과 판단

- **대상·진입:** D까지 [관찰 목록](candidate-selection.md)을 다시 구성하고, 종가가 D 제외 직전 20일 고가 최댓값을 초과하면 신호를 기록한다. 현재 관찰 종목을 과거에 고정하지 않는다.
- **청산 비교:** 고정 만기 5/10일, 첫 초안, 돌파 기준 이탈 5/10일, 신호일 ATR14를 고정한 2ATR 추적 5/10일의 총 7안. 추적선은 이전 종가 최고값으로만 올린다. 고정 익절 목표는 두지 않았다.
- **시점:** 완료 종가 판단 → 다음 거래일 시가에 가격 불리함·[규정 비용](competition-rules.md#거래와-집계)을 적용한다. 만기는 진입일을 1일째로 세어 마지막 보유일 종가 후 다음 시가 청산이다. 저가의 손절선 접촉을 당일 체결로 처리하지 않는다.
- **보유 상태:** 종목별 중복 진입을 막은 결과를 별도로 계산한다. 결측은 미확정, 미청산은 계속 보유 상태로 남긴다. 0거래량·단일가격 봉은 진입 취소/청산 지연 시나리오로 처리했다. 이는 일봉 전체를 본 사후 체결 진단으로, 시초가 주문 가능성을 입증하지 못한다.
- **선택:** [성과 계산 전 비교 계획](../research/daily-trend/plan.json)의 비용·기간·표본·시장별 차이·불확실성 조건을 적용한다. 개발/검증 선택을 해시로 봉인한 뒤 재사용 구간을 평가했고 재선택하지 않았다. 현재 selected_rule은 null이다.

기존 연구에 사용한 **모든 과거 기간은 탐색 자료**다. 20일 블록 재표집과 7비교 보정도 과거 지식·고정 종목군·수정주가 편향을 없애지 못한다. 이 원칙은 [백테스트 과최적화 연구](https://www.davidhbailey.com/dhbpapers/backtest-prob.pdf)를 참고했다. 자료 한계는 [기존 연구](candidate-selection.md#해석-범위)를 따른다. 개발 1건·검증 2건의 진입 취소를 원표본에 보존했으며 미확정 수익을 0으로 채우지 않았다.

## 조정 후 회복 추가 연구

기존 상승추세에서 이틀 조정한 뒤 전일 고가를 종가로 회복하는 가설 하나를 추가했다. 청산은 5거래일 보유 후 다음 시가로 고정했다. [계획·수식](../research/pullback-recovery/plan.json)과 코드를 **성과 계산 전 2026-10-05 00:30:57 KST에 봉인**했으며 결과를 보고 조건을 조정하지 않았다.

[Adam Grimes의 추세 복귀 설명](https://www.adamhgrimes.com/fundamental-trading-patterns/)은 구조적 참고다. 이동평균·2일 조정·5일 보유 수치는 우리의 미검증 정의다. [단기 반전 연구](https://academicweb.nd.edu/~zda/Reversal.pdf)는 기업가치 관련 뉴스와 무관한 하락의 반전을 구분하지만, 미국 월간 자료의 결과로 한국 일봉 수익성을 입증하지 않는다.

| 기본 비용 결과 | 개발 | 검증 | 재사용 |
| --- | ---: | ---: | ---: |
| 신호일 평균 거래손익 | −0.36% | −0.78% | −2.67% |
| 같은 날짜·시장 추세 대조군 대비 | −0.52%p | −2.46%p | −0.89%p |
| 완결 사건 / 신호일 | 89 / 69 | 74 / 40 | 7 / 6 |

기본 비용은 앞 표와 같다. 시장별 평균을 당일 관측 신호 수로 가중한 뒤 날짜를 동일 가중한다. 대조군은 동일 관찰 목록에서 추세 조건만 충족한 종목이며 신호 종목을 포함한다. 검증 차이의 95% 구간은 **−4.11~−0.63%p**로, 우위 대신 열위가 관측됐다. 편도 슬리피지 0.2%에서도 세 기간 평균은 음수다. 전 기간이 재사용 자료이며, 원표본 90/75/9건 중 기간 경계 1/1/2건을 제외했다. 신호의 자료 미확정·체결 불확실은 0건이다.

[분석기](../research/pullback-recovery/analyze.py)·[결과](../research/pullback-recovery/results.json)·[봉인 원본](../.local/research/pullback-recovery-2026-10-05/freeze.json). 공유 규칙·별도 벡터·직접 합계식의 관찰 후보 12,200건이 일치했고 합성 테스트 14개를 통과했다. [독립 검산](../research/pullback-recovery/verify_results.py)은 신호·대조군의 비용별 2,592경로와 날짜·시장 집계 472행의 원가격·진입 조건·시점·계산을 확인했다. 계좌 성과·실체결 검증은 아니다.

## 재현과 현재 범위

[별도 연구 환경 의존성](../research/daily-trend/requirements.txt)을 설치한 Python에서 실행한다. 원본은 [기존 연구 자료](../.local/research/candidate-screen-2026-10-04/manifest.json)가 필요하다.

```powershell
python research/daily-trend/analyze.py --stage develop --output .local/research/daily-trend-2026-10-04-v2
python research/daily-trend/analyze.py --stage audit --output .local/research/daily-trend-2026-10-04-v2
python -m unittest discover -s research/daily-trend -p "test_*.py"
```

규칙·데이터가 바뀌면 새 출력 폴더를 사용한다. 첫 계산은 결과 확인 전 검산 수정으로 중단했으며 중단 흔적도 보존했다. 연구 테스트 43개·기존 연구 16개, 공개 엔진 대조 210건, 비용식 10,128건과 [대조군 독립 재구성](../research/daily-trend/verify_baseline.py) 261일·5,220경로가 일치했다.

[기존 돌파 연구 신호](../.local/research/daily-trend-2026-10-04-v2/audit-signals.json)는 과거 분석 산출물로 유지한다. 새 가설 재현은 별도 연구 환경에서 실행한다. 원본·코드가 바뀌면 새 출력 폴더로 봉인한다.

```powershell
python research/pullback-recovery/analyze.py freeze --output .local/research/pullback-recovery-new
python research/pullback-recovery/analyze.py run --output .local/research/pullback-recovery-new
python -m unittest discover -s research/pullback-recovery -p "test_*.py"
python research/pullback-recovery/verify_results.py --output .local/research/pullback-recovery-2026-10-05
```

## 전진 관찰

서버의 **후보 탐색 → 전진 관찰**은 조정 후 회복 가설을 미채택 연구로 기록한다. 서버 실행과 저장 위치는 [README](../README.md)를 따른다. 최초 실행에서 룰·계획·선별 코드·종목군의 버전을 봉인하고 일봉 기준일·수신 시각·판정 시각·입력 해시를 보존한다. 같은 날 최초 판정과 관찰 목록은 재조회로 덮어쓰지 않는다.

봉인 이전 거래일은 초기 이력, 다음 개장 이후 생성한 판정은 지연 기록으로 분리하며 전진 성과에서 제외한다. 주말·휴일 등 다음 개장 시점이 불명확하면 시점 확인 대기로 남기고, 실제 후속 지수 거래일을 받은 뒤 원래 생성 시각과 비교한다. 완료 일봉 판단 후 다음 거래일 시가를 가상 진입가격으로 사용한다. 가격 조회 시각은 실제 체결 시각이 아니다. 수정주가 변경·결측·체결 불확실은 보류하고, 무신호·부분 수집·변경 자료도 원본에 남긴다.

**10월 9일은 수집 진단, 11월 20일은 고정 평가 시점**이다. 날짜는 대회 일정에 맞춘 것이며 충분한 증거가 모인다는 뜻은 아니다. [계획](../research/pullback-recovery/plan.json)의 비용 후 우위·불확실성·표본·시장별 조건을 평가하며 부족하면 미채택으로 남긴다. 새 자료에서 우위가 확인되어도 배분·모의 주문·체결·복구 검증을 거쳐야 운용할 수 있다. 자동 주문으로 전환하지 않는다.
