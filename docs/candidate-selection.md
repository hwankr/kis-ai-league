# 관찰 후보 선정

완료된 일봉으로 다음 거래일에 검토할 종목을 좁힌다. **2026-10-04 결정: 추세 추가 조건은 채택하지 않고, 거래 상태·자료·유동성을 확인한 평균 거래대금 상위 20종목을 기본 관찰 목록으로 사용한다.** 수익 개선이 검증된 매수 목록을 뜻하지 않는다. 적용 파일은 [선정 정책](../config/candidate-selection.json)이다.

## 운영 기준

| 항목 | 기준·이유 |
| --- | --- |
| 대상 | [대회 기준 목록](../config/competition-universe.json). 당시 KRX 지수 구성자료이며 주최측 실제 주문 허용을 완전히 확인한 목록은 아니다. |
| 거래 상태 | [거래 제한 규정](competition-rules.md)에 따라 조회 원주가 1,000원 이상과 현재 상태를 확인한다. 시장경보·투자주의환기·단기과열도 보수적으로 제외하며, 미확인 상태는 통과시키지 않는다. |
| 유동성 | 기준일 포함 20거래일 평균 거래대금 **100억원 이상**. 대회 원금 전액도 평균 거래대금의 1% 이내가 되도록 정한 운영값이며, 수익률 최적값이나 체결 보장이 아니다. |
| 자료 | 최근 20거래일 모두 거래량 양수, 연속 61거래일 유효 일봉. 장기 지표를 채택하면 해당 지표의 전체 기간도 필요하다. 결측일을 건너뛰거나 0으로 채우지 않는다. |
| 개수 | 조건 적용 후 최대 **20종목**. 검토할 수 있는 목록 크기로 정했으며, 동점은 종목코드 순이다. |

거래 상태는 KIS 공식 종목 마스터와 현재가 응답으로 확인한다. 마스터 다운로드 시각은 상태의 효력 거래일을 증명하지 않으며, 규정의 ‘감리’·‘저유동성’과 모든 API 필드의 완전한 대응은 미확인이다. 위 추가 제외는 자체 운영 정책이다.

## 연구 근거와 검증

- [MSCI의 2025년 4월 방법론](https://www.msci.com/indexes/documents/methodology/2_MSCI_Momentum_Indexes_Methodology_20250417.pdf)은 최근 1개월을 제외한 6·12개월 성과와 변동성을 사용한다. 현재 화면의 5·20일 강세와 같은 검증을 뜻하지 않는다.
- 한국 주식 연구는 최근 성과의 반전과 측정 기간에 따른 차이를 보고한다. 따라서 **20/60일선·거래대금 1.5배를 확정된 최적값으로 취급하지 않는다.** [Sim·Kim(2021)](https://doi.org/10.1108/JDQS-02-2021-0005), [Eom·Park(2026)](https://onlinelibrary.wiley.com/doi/10.1111/irfi.70072).

[사전 고정 계획](../research/candidate-screen/plan.json)에 따라 12개 비교안을 개발·검증 기간에서 평가하고 하나를 봉인한다. 신호일 종가로 선정한 뒤 다음 거래일 시가→5거래일째 종가를 주 평가로 사용한다. 대회 비용과 편도 슬리피지 0.1%를 반영하며, 1·20거래일과 비용 민감도도 확인한다.

최종 기간에서는 봉인한 한 조건만 평가한다. 기준군 대비 차이·95% 구간 하단·양시장 차이와 비용후 수익 조건을 모두 통과해야 추가 조건을 채택한다. 누락·미통과·선택 없음이면 유동성과 거래 상태를 확인한 거래대금 상위 20개를 기본 관찰 목록으로 사용한다. **기본 목록의 수익 개선을 입증했다는 뜻은 아니다.** 정확한 문턱·날짜·비용·계산식은 계획을 따른다.

## 평가 결과

개발·검증에서 봉인한 조건은 `trend_rs20_60`: 종가 > 20일선 > 60일선, 20일선 상승, 20·60일 지수 대비 수익률 양수, 60일 상대강도 상위 20개다. 이후 최종 기간을 한 번 평가했으며 재선택하지 않았다.

## 해석 범위

2026-09-21의 고정 종목·소속시장을 과거에도 적용하므로 편입·생존·시장 분류 편향이 남는다. 과거 거래 제한과 당시 원주가를 복원하지 못했으며 현재 수정주가를 사용한다. 결과는 배당을 제외한 일별 후보 묶음의 수익률 진단이며 계좌 누적 수익률·장중 진입 조건 검증이 아니다.
