# 모의투자 대회 핵심 규정

## 2026 한투모투배틀 AI리그

확인: 2026-10-10, 한국시간 기준. OpenAPI 개인 모의투자 리그이며 **원금 1억 원, 최종 수익률 순위**로 평가합니다.

### 일정

| 일정 | 날짜 및 시간 |
| --- | --- |
| 참가 신청 | 2026-09-21 ~ 2026-10-31 |
| 대회 | **2026-10-12 ~ 2026-11-20** |
| 수익률 초기화 신청 | **2026-10-12 ~ 2026-10-16, 1회** |
| 수상자 검증 | 2026-11-23 ~ 2026-11-27 |
| 재학 또는 휴학 증빙 제출 | **2026-11-30 17:00까지** |
| 최종 수상자 발표 | 2026년 12월 초 예정 |

### 수상에 필요한 조건

모든 요건을 충족해야 하며 **수익률이 음수이면 시상 제외**됩니다.

| 항목 | 기준 |
| --- | --- |
| 매매일 수 | **5영업일 이상** 체결 발생 |
| 누적 매매금액 | **매수와 매도 체결금액 합계 5억 원 이상** |
| 거래 종목 수 | **서로 다른 5종목 이상** 체결 |
| AI리그 추가 조건 | **OpenAPI 체결 5회 이상**. 분할체결은 주문당 1회 |
| 학생 증빙 | 마감 전 재학증명서 또는 휴학증명서 제출 |

### 거래와 집계

| 항목 | 규정 |
| --- | --- |
| 투자 대상 | **2026-09-21 기준 코스피200·코스닥150**. 본문은 대회 중 목록 유지로 명시하나 하단 운영표와 상충하므로 실제 허용 목록 확인 필요 |
| 거래 제한 | 거래정지·실제 거래가 없는 종목, 1,000원 미만 종목, 관리·감리종목, 우선주, 유동성이 낮은 종목 등 |
| 매매 | 현금 매수·매도만 가능. **미수·신용·공매도 불가**, 증거금 100% |
| 주문 유형 | 지정가·시장가·최유리·최우선 |
| 정규시장 | 09:00~15:30 |
| 동시호가 | 08:30~09:00, 15:20~15:30 |
| 예약주문 접수 | 당일 15:40~익일 07:30, 동시호가에 제출 |
| 주식 비용 | 규정표상 수수료 **0.0140527%**, 세금 **0.20%**. 사이버머니에서 차감 |
| 수익률 | `(총평가금액 − 1억 원) / 1억 원 × 100`. 보유 주식 평가금액과 거래 비용 반영 |
| 동률 처리 | 거래금액이 많은 순서, 그다음 거래일 수가 많은 순서 |

- 실제 시장 체결·거래량에 따라 모의 체결됩니다. 장 마감 전 미체결 주문은 **16:00까지 체결 가능**하며, 장 마감 후에는 예약주문만 별도 접수합니다.

- 초기화는 다음 날 장 시작 전 반영됩니다. **수익률·거래일·금액·종목 수가 초기화**되며 API 횟수 처리 방식은 미확인입니다.

- 동일 IP·복수 ID·허수성·가장·통정성 거래·고의적 반복 단일 종목 매매는 수상 제한 사유입니다. 자동매매 적용 기준은 확인이 필요합니다.

## 타임폴리오 제13회 RFM

확인: **2026-10-10**, 한국시간 기준. 가상 운용자금 **10억 원**이며, 위 KIS 대회와 별도 계좌·규정으로 운영됩니다.

### 일정과 평가

- 대회: **2026-10-01~11-30**. 참가 신청·포트폴리오 리셋은 **10-08 마감**했습니다.
- 리셋은 시작 후 첫 5거래일 이내 1회, 다음 영업일부터 거래하는 방식입니다. 현재 신청 기간은 종료됐습니다.
- 수익률 상위 5명에게 총 **2,000만 원**을 시상합니다. 별도 운용능력 평가는 수익 분산·포트폴리오 집중도·수익률 등을 반영하며, A+는 상대평가입니다.
- 1인 1ID이며 타인 계정을 사용할 수 없습니다. 포트폴리오는 닉네임으로 공개됩니다.

### 주문과 비용

| 항목 | 규정 |
| --- | --- |
| 주문 단위 | 순자산 대비 **비중**을 입력하며 접수 시 수량으로 환산. 실제 시장 가격·시장 충격을 반영하므로 부분체결 가능 |
| 가격·시간 | 자기/상대호가 1~10호가, 지정가, STOP. 즉시 실행 또는 시간 분할 |
| 접수 | 당일 08:00 이전 입력은 08:00에 유효성 검사·접수, 이후 입력은 즉시 검사 |
| 정정 | 접수 후 가격·가격 유형만 정정 가능. 비중·시간 변경은 기존 주문 정지 후 새 주문 |
| 비용 | 매수·매도 각각 수수료 **0.1%**, 매도 세금 **0.2%** |
| 시세 화면 | 호가·차트·시세를 재배포하지 않으므로 증권사 화면 등에서 확인 |

### 운용 제한

| 항목 | 규정 |
| --- | --- |
| 대상 | KRX 코스피·코스닥 보통주. DR·우선주·ETF 및 NXT 거래 제외 |
| 매수 제한 | 최근 5일 평균 거래대금 **30억 원 이하**, 시총 **1,000억 원 미만**, 상장 후 **6거래일 미만**, 투자주의·경고·위험·환기·관리 종목 등 |
| 종목 한도 | **15%**, 예외: 삼성전자 **40%**, SK하이닉스 **30%**. 2026-07-01 적용 변경 공지 기준 |
| 섹터 한도 | **max(시장 섹터 비중 × 2, 10%)**. 종목 GICS 분류는 대회 시작 직전 거래일 기준으로 고정. 시장 비중·여력은 사이트 표에서 확인하며 미체결 매도는 여력에 선반영하지 않음 |
| 소형주 한도 | 시총 **1조 원 미만** 종목의 합계 비중 **30% 이하** |
| 주간 회전율 | `(매수 체결액 + 매도 체결액) / 기간 평균 순자산 × 0.5 × 100`이 **5% 이상**. 미달은 3주까지 허용, 4주부터 순위·시상 제외 |

- **10-05~10-09 주간 회전율은 면제**, 10-12부터 정상 적용합니다.
- 가격 변동에 따른 일시적 한도 초과는 신속히 조정해야 하며 지속 위반 시 시상에서 제외될 수 있습니다. 기업행사는 별도 조정되므로 매뉴얼을 확인합니다.
- 일요일 07:00~09:00 점검 가능 시간이 있습니다.
- **참가자용 공개 API 문서와 자동화 관련 공식 안내는 확인되지 않았습니다.**
